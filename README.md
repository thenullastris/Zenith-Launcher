## 🚀 Installation

### ![TrollStore](https://img.shields.io/badge/TrollStore-Recommended-brightgreen?logo=apple) Method 1: TrollStore

> Perfect for permanent installation with **auto-JIT** and increased memory limits.

```
1. Download the latest Zenith Launcher IPA from Releases
2. Open the IPA in TrollStore via the share menu
3. Install and launch! 🎉
```

### ![AltStore](https://img.shields.io/badge/AltStore%20%2F%20SideStore-Alternative-blue?logo=apple) Method 2: AltStore / SideStore

> Alternative sideloading method *(requires weekly re-signing)*.

```
1. Download the latest Zenith Launcher IPA from Releases
2. Open in AltStore or SideStore to install
3. Follow JIT enablement steps below
```

### ![Nightly](https://img.shields.io/badge/Nightly%20Builds-Experimental-orange?logo=github) Method 3: Nightly Builds

> [!WARNING]
> May contain experimental features and bugs.

```
1. Download from the Actions tab on GitHub
2. Install via your preferred sideloading method
```

> **Important:** Only install from trusted sources. We are not responsible for harm caused by unofficial software.

## ⚙️ Enabling JIT

Zenith Launcher requires **Just-In-Time (JIT) compilation** for optimal performance.

|Method      |💻 Requires Computer|📶 Requires Wi-Fi|✅ Auto-Enabled|
|------------|:-----------------:|:--------------:|:------------:|
|🏪 TrollStore|❌                  |❌               |✅             |
|🔓 Jailbreak |❌                  |❌               |✅             |
|🔵 AltStore  |✅                  |✅               |✅ *           |
|🟣 SideStore |✅ **               |✅ **            |❌             |
|⚡ Jitterbug |⚠️ ***              |✅               |❌             |


> * Requires AltServer running on local network  
> ** Only required the first time  
> *** Only if VPN is unavailable
